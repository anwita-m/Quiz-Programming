# Quiz Programming (C++)
## Description
This is a simple quiz application written in C++. It asks the user MCQ and calculates the final score
## Features
- Multiple-choice questions
- Calculates Score
## Technologies Used
- C++
## Process of code running:
1. Compile the code:
g++ quiz.cpp -o quiz
2. Run:
./quiz
